# Public helper registry

This registry is the durable authority for public per-skill helper identity and
membership. A listed helper is a required workflow action; an executable absent
from this catalog is internal. The catalog is navigation only: local usage
contracts own reusable mechanics and owning skills own workflow judgment.

## Explicit exclusions

- `skills/devcanon-runtime/scripts/**` is internal support-bundle operation.
- `skills/issue-worktree-setup/scripts/setup-worktree.sh` is an internal POSIX
  adapter; `setup-worktree.mjs` is the public helper.
- `skills/play-skill-authoring/scripts/render-graphs.js` is optional rather
  than a required workflow action.
- `skills/play-validate-review-artifacts/scripts/review-artifacts.sh` is an
  internal support-only adapter; its owning skill forbids standalone use.
