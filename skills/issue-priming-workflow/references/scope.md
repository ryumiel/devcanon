# Scope — `issue-priming-workflow`

- Interactive preparation uses the shared delivery choice unless the user
  already selected an endpoint. Preparation-only preserves the handoff. Local
  delivery implements and verifies locally. PR delivery uses the existing
  review and publication gates.
- Explicit `--auto` selects PR delivery. Settled work uses a guarded Execution
  Note and same-owner inline execution. Work needing design retains its
  investigation, design, and reviewed planning route.
- A durable owner referral follows the existing discard path. Genuine design
  ambiguity and authority gaps take their existing decision gates. Merge is a
  separate workflow.
